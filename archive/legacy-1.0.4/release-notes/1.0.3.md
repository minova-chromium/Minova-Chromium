# Minova Chromium 1.0.3

Version 1.0.3 makes Minova adaptable to both traditional browsing and larger multi-context workflows.

## New interfaces and workflows

- **Workspace UI:** Use a collapsible vertical-tab sidebar with color-coded contexts and live site icons.
- **Classic UI:** Keep a complete traditional horizontal-tab layout without losing Minova features.
- **Custom workspaces:** Create, rename, recolor, reorder, and remove contexts while their tabs remain alive.
- **Split View:** Tile and interact with two regular webpages inside one Minova window.
- **Visual first-launch tour:** Choose an interface, learn the major browser tools, and finish with secure Google Password Manager transfer.
- **Replayable setup:** Open the complete Minova tour again from Settings at any time.

## Streaming and media improvements

- Streaming Mode now coordinates with both interface layouts and automatically collapses the workspace rail.
- Split View is exited before Streaming Mode can start, preventing overlapping native views.
- The attached protected-playback surface follows window movement, resizing, minimize and restore, and fullscreen transitions more reliably.
- Streaming playback can remain paused in the background while another tab is active and resume without rebuilding the session.
- Closing the owning tab now closes its Streaming Mode surface as well.

## Reliability and polish

- Expanded automated coverage for onboarding, workspace editing, tiled views, Classic UI, and streaming lifecycle behavior.
- Improved native-window cleanup and shutdown behavior.
- Updated the Minova website with the complete interface catalog, first-launch tour, current screenshots, and the 1.0.3 changelog.
- Added a versioned GPL-3.0 application-source archive alongside the installer and updater assets.

Download **Minova-Chromium-Setup-1.0.3.exe** for a new installation. Existing installations can update through Minova's background updater.
