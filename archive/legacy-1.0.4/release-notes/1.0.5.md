# Minova Chromium 1.0.5

Version 1.0.5 adds a third complete interface, introduces Minova's Liquid Glass theme, and rolls out the new visual identity across the browser and its release system.

## Safari-Style Interface

- **Third complete layout:** Choose Workspace, Classic, or the new Safari-style interface without losing Minova features.
- **Focused Smart Search:** A centered omnibox anchors the toolbar while navigation, extensions, Minova tools, and the menu remain within reach.
- **Tabs below the address bar:** Rounded horizontal tabs sit on their own compact row and retain live favicons, close controls, and new-tab behavior.
- **Traffic-light controls:** Safari mode uses clear close, minimize, and maximize controls while preserving expected Windows behavior.
- **Softer light mode:** The Safari light appearance uses restrained cool surfaces instead of harsh pure white.

## Liquid Glass Theme

- **Layered translucent chrome:** The toolbar and tab strip use glass blur, saturation, highlights, and controlled depth.
- **Readable by design:** Text, active tabs, icons, and menus preserve practical contrast across the glass surfaces.
- **One-step setup:** Selecting Liquid Glass automatically enables the compatible Safari-style layout.
- **Persistent preferences:** The selected interface and theme return after restart.

## New Minova Identity

- **Prism M symbol:** A new geometric app mark now represents Minova across the browser, installer, executable, website, and release artwork.
- **Custom wordmark:** The approved MINOVA lettering and cyan O segment form the primary horizontal lockup.
- **Complete brand kit:** SVG masters, Windows icons, PNG exports, design tokens, templates, usage rules, and a browser-based brand guide now ship together.
- **Consistent product assets:** Runtime icons and release assets use the same authoritative source artwork.

## Windowing & Reliability

- **Native movement in Safari mode:** Restored reliable dragging and resizing for the frameless browser window.
- **Window controls:** Minimize, maximize/restore, and close remain interactive in all three layouts.
- **Stable chrome geometry:** Safari and Liquid Glass retain the expected toolbar and tab-strip height through layout changes.
- **Automated regression coverage:** Added checks for theme persistence, Safari layout activation, glass rendering, active-tab geometry, and chrome height.

## Distribution

- **Updated website:** The public site now documents Safari UI, Liquid Glass, the new identity, and the complete 1.0.5 changelog.
- **Release film:** A new versioned promotional video joins the permanent update-video archive.
- **GPL-3.0 source:** The source archive now includes the full visual identity sources alongside the application code.

---

## How to Install / Update

- **Existing users:** Open the three-dot menu and select **Check for Updates**, or let Minova download the update quietly and install it when you restart.
- **New installations:** Download and run **`Minova-Chromium-Setup-1.0.5.exe`** from the assets below.
