Everyday browsing

Real Chromium pages

Smart omnibox

Navigate directly or search from one field, with suggestions from recent pages and previous searches as you type.

Session restore

Continue with regular tabs after restarting. Private tabs are intentionally never written into the saved session.

Tabs that work like tabs

Open, close, pin, restore, reorder through normal workflows, and close the final tab to exit the browser.

History and bookmarks

Browse recent history and saved bookmarks directly from the three-dot menu or dedicated management pages.

Find, print, and downloads

Native find-in-page results, printing, download tracking, and quick access to completed files.

Interfaces and workspaces

Choose vertical contexts, familiar horizontal tabs, or Minova's focused Safari-style arrangement.

Workspace UI

Use a collapsible left rail with vertical tabs, live favicons, workspace colors, and focused commands.

Classic UI

Keep traditional horizontal tabs while retaining Minova's themes, extensions, passwords, media tools, and Streaming Mode.

Safari-style UI

Use traffic-light controls, a centered Smart Search field, integrated extension actions, and rounded tabs below the toolbar.

Liquid Glass

Add layered translucency, blur, highlights, and saturation with practical contrast and a restrained light appearance.

Editable workspaces

Create, rename, recolor, reorder, and delete contexts. Personal, Work, and Gaming are starters, not permanent restrictions.

Instant context switching

Move between workspaces without destroying their tabs. Each context remembers its active page and arrangement.

Split View

Tile two normal webpages side by side inside one Minova window, with native views that resize and remain independently interactive.

Visual first-launch tour

Preview Minova's interface choices, learn the browser's power features, and finish with secure password import. The tour is always replayable.

Nine independent colors

Search engine choice

Home and startup controls

Choose a home page and decide whether Minova restores your session, opens New Tab, or starts somewhere specific.

Privacy and passwords

Useful protections that stay understandable and close to the browsing experience.

Built-in ad and tracker blocking

Filter common advertising and tracking requests with locally cached, regularly refreshed block lists.

Encrypted local vault

Credentials are protected using Electron safeStorage backed by Windows encryption, never written to a plaintext password file.

Account suggestions

Saved logins for the current site appear where account forms need them, with autofill controls in Settings.

Private tabs

Browse in an isolated private session that does not enter Minova's saved history or session restore.

Granular site permissions

Control notifications, camera, microphone, location, pop-ups, and Do Not Track behavior.

Delete browsing data on demand, clear all history at once, or erase browser data automatically when Minova closes.

Extension compatibility

A practical Chrome-extension layer with clear expectations about Electron compatibility.

Load compatible extensions with common runtime, storage, tabs, windows, permissions, cookies, and context-menu APIs.

Chrome Web Store installer

Paste a Web Store URL or extension ID and let Minova fetch and install the extension package.

Load unpacked

Developers can select a local folder containing a manifest and test an extension directly.

Pinned extension actions

Pin compatible extension icons beside the address bar and open their popups without leaving the current page.

Minova Assistant

A private, page-aware assistant that runs through WebGPU on your own computer. Page text and conversations are processed locally instead of being sent to an AI service.

Local model and offline cache

The model downloads once, is stored in Minova's isolated IndexedDB partition, and can keep working offline after setup. WebGPU provides hardware acceleration without Ollama or another background application.

Page-aware conversation

Enable Use page to ask grounded questions about the active webpage. Minova bounds and sanitizes the reference so page instructions cannot take control of the assistant.

Research tools

Summarize a page, extract key points and action items, build an outline, identify useful structured data, or analyze claims against the evidence actually present on the page.

Writing tools

Select text on a webpage to explain, simplify, rewrite, or proofread it. Minova can also draft a concise reply while avoiding invented personal details.

Study tools

Turn long reading into a structured study guide or a five-question quiz with an answer key, all grounded in the active page.

Split View comparison

Open two normal webpages in Split View and choose Compare tabs. The assistant highlights common ground, differences, contradictions, and unique details from both pages.

Getting started

Use the sparkle button in Minova's toolbar.

  1. Open a webpage, then open Minova Assistant.
  2. Choose a page tool or enable Use page for follow-up questions.
  3. Select text before using selection tools such as Proofread or Draft reply.
  4. Open More tools for study, research, writing, and Split View actions.

Privacy note: Normal conversations are saved locally for continuity. Conversations started from a private tab are kept out of persistent assistant history.

Minova Audio Studio

Per-tab volume, transparent loudness control, and detailed tone shaping in one toolbar panel. Settings follow compatible HTML audio and video without altering the original media file.

Tab volume

Raise compatible media from 100% to 300% for unusually quiet sources. Start low and increase gradually to protect your hearing and speakers.

Dynamic normalizer

The compressor reduces harsh volume jumps. Threshold decides when it works; ratio controls strength; knee smooths the transition; attack and release control how quickly it reacts and recovers.

Ten-band parametric EQ

Each band exposes frequency, gain, and Q. Frequency chooses the tone, gain boosts or cuts it, and Q controls whether the adjustment is broad or narrow.

Automatic headroom

Auto headroom lowers the preamp when EQ boosts could clip. The safety margin adds extra protection, while Output provides a deliberate final level adjustment.

Presets

Start with Flat, Bass Boost, Vocal Clarity, or Night Mode. Name and save custom settings, update them later, or delete presets you no longer need.

Efficient by design

The AudioContext follows playback and suspends while media is idle. Audio Studio reports active sources, compressor reduction, unavailable players, and protected-media limitations.

Getting started

Open the speaker control beside the address bar.

  1. Play audio or video in the active tab.
  2. Choose a preset or enable the Normalizer and EQ separately.
  3. Keep Auto headroom enabled when boosting EQ bands.
  4. Save the finished curve as a named preset for later use.

Compatibility: Some protected or cross-origin players do not expose their audio graph. Streaming Mode uses the certified playback path and therefore cannot be processed by Minova Audio Studio.
