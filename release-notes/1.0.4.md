# Minova Chromium 1.0.4

Version 1.0.4 brings private local AI and professional audio controls directly into Minova, alongside another focused round of interface and reliability improvements.

### ✨ Private Minova Assistant

* **Runs Locally:** The Minova Assistant uses WebLLM and WebGPU directly inside the browser, without Ollama, a cloud API, or another background application.
* **Offline Model Cache:** The lightweight local model downloads once, is stored in IndexedDB, and remains available offline after setup.
* **Streaming Chat:** Responses appear progressively in the Assistant sidebar with local conversation history, copy controls, and a clean new-chat workflow.
* **Page-Aware Tools:** Summarize pages, extract key points and action items, explain or rewrite selected text, create study guides and quizzes, build outlines, analyze claims, extract structured data, simplify text, proofread writing, and draft replies.
* **Split View Comparison:** Compare the content of both visible Split View tabs from one Assistant action.
* **Long-Page Reliability:** Large webpages are compacted and retried safely, preventing `ContextWindowSizeExceededError` failures when content exceeds the model's context window.
* **Built-In Guidance:** A new help button opens the complete Minova Assistant guide on the Minova website.

### 🎚️ Minova Audio Studio

* **Integrated Volume Control:** The toolbar volume-booster button now opens the complete Minova Audio Studio.
* **Universal Audio Processing:** Apply per-tab volume boost, transparent dynamic-range normalization, and a ten-band parametric equalizer to compatible HTML5 audio and video.
* **Audiophile Controls:** Adjust compressor threshold, knee, ratio, attack, and release, plus every EQ band's frequency, gain, and Q factor.
* **Safer Gain Staging:** Automatic headroom management helps prevent clipping when EQ bands or volume are boosted.
* **Custom Presets:** Save, load, rename, and delete local Audio Studio presets, with useful starting profiles and a true flat mode.
* **Efficient Lifecycle:** Audio processing sleeps when media is idle and follows dynamically created media elements.
* **Built-In Guidance:** A dedicated help button opens the Audio Studio setup, controls, compatibility, and troubleshooting guide.

### 🛠️ Interface & Reliability

* **Window Controls:** Repaired the custom minimize, maximize/restore, and close controls by separating the native draggable titlebar region from the interactive buttons.
* **Classic UI Polish:** Restored the compact Classic UI titlebar arrangement, including the new-tab button beside the active horizontal tabs.
* **Streaming Geometry:** Preserved Streaming Mode geometry and toolbar alignment across both Classic and Workspace interfaces while applying the titlebar fixes.
* **Trusted Assistant Bridge:** Improved Assistant IPC validation so page text and help navigation remain scoped to trusted Minova surfaces.
* **Automated Coverage:** Expanded regression testing for local AI initialization, all Assistant tools, Audio Studio, help links, packaged resources, and native window controls.

### 📚 Documentation & Distribution

* **Website Guides:** Expanded the live Features page with complete Minova Assistant and Audio Studio guides.
* **Release Assets:** Updated updater manifests, checksums, release metadata, and the versioned GPL-3.0 application-source archive for 1.0.4.

---

### 📥 How to Install / Update

* **Existing Users:** Open the three-dot menu and select **Check for Updates**, or allow Minova to download the update silently in the background and install it when you restart.
* **New Installations:** Download and run **`Minova-Chromium-Setup-1.0.4.exe`** from the assets below to get started.
